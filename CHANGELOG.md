# Changelog

## 0.2.0

- Rename the domain/folder to `onkyo_extended` and display name to Onkyo Extended.
- Add input and listening-mode selectors alongside Network Services.
- Add Configure visibility lists and optional dashboard checkbox menus.
- Add Quick Menu, Movie/TV, Music, Game and Shuffle buttons.
- Provide Main Zone and supported secondary-zone media players.
- Use Title Case display names and a decimal-minute fallback refresh timer.
- Share one paced, reconnecting local connection and cache push updates.

Partially tested on an HT-R997 only; see README for firmware and limitations.
